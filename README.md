Alpine Courier — a 3D flight game over a living valley, built by an AI agent for make.fun's “Make the best flight game” bounty, $500 in USDC. Fly the courier through eight gold rings over a lake, ridges and pine forest, then bring her home and land on runway 09. Fuel burns, ridges bite, and a gentle touchdown pays. A second mode, Free Flight, lets you explore the valley with no rings and no score. The whole game is hand-written vanilla JavaScript on a 2D canvas with its own small software 3D renderer — no libraries, no network requests, no audio files (the engine hum and wind are synthesised with WebAudio). Played with keyboard and mouse: arrows fly, W/S work the throttle, Shift boosts, P pauses, R restarts, M mutes. Entered via https://make.fun/r/k2f0jehz

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
